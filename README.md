# minesbot

# Moderation Discord Bot

## ✨ Features

### 🧠 XP & Leveling
- XP system
- Level-up announcements
- XP cooldown system
- Image-based leaderboard
- Circular avatars & progress bars

### 🏆 Leaderboard
- Top 10 server leaderboard
- Medal ranks (🥇🥈🥉)
- Level & XP progress bars
- Dark UI

### 🛡 Moderation
- Auto-moderation:
  - Anti-link system
  - Spam detection (auto-timeout)
- Manual moderation commands:
  - `/warn`
  - `/warnings`
  - `/timeout`
  - `/clear`
  - `/kick`
  - `/ban`
- Full **mod-log** logging (embeds)

### 👋 Server Systems
- Welcome & goodbye messages (embeds)
- Autoroles on join
- Configurable level-up channel
- Configurable mod-log channel

### 🎉 Fun Commands
- `/ping`
- `/coinflip`
- `/roll`
- `/8ball`
- Secret trigger words (banana, skill issue, etc.)

---

- **Python 3.11** (recommended)
- Discord bot with Message Content intent enabled
